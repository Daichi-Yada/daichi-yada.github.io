# 矢田大地のホームページ

https://daichi-yada.github.io/

平成の個人ホームページをイメージした、軽量な静的サイトです。
GitHub Pages の `main` ブランチ、`/docs` フォルダから公開します。

## 更新方法

各ページの HTML を編集し、`main` に push すると公開内容が更新されます。
最終更新日も各ページのフッターで変更してください。

- `docs/index.html`：トップ・近況
- `docs/profile.html`：自己紹介・経歴
- `docs/research.html`：研究紹介
- `docs/works.html`：学会発表・活動
- `docs/personal.html`：音楽・スポーツ
- `docs/links.html`：リンク集
- `docs/style.css`：共通の見た目・スマートフォン対応
- `docs/assets/portrait.jpg`：プロフィール写真（元画像のメタデータは除去）

ローカル確認：`python3 -m http.server 8000 --directory docs`

公開用に整理した内容だけを収録しています。経歴の参照資料、未公表の研究資料、住所などの個人情報は含めていません。
