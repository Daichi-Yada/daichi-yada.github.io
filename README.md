# 矢田大地 / Daichi Yada

https://daichi-yada.github.io/

経歴・論文・学会発表を一覧する個人ホームページ。
GitHub Pages の `main` ブランチ、`/docs` から公開。

- `docs/index.html`：本文
- `docs/style.css`：レイアウトとスマートフォン対応
- `docs/assets/portrait-2025.jpg`：指定写真の静止画（メタデータ除去済み）
- 旧プロフィール・研究・業績・リンクのURLは、トップ内の各項目へ転送

更新時は HTML を編集し、`main` に push。
ローカル確認：`python3 -m http.server 8000 --directory docs`
